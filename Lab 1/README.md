# Experiment 1 — Single Layer Perceptron for Binary Classification
CS3807 Deep Learning Laboratory,  2026-27

## Dataset
UCI Banknote Authentication Dataset
https://archive.ics.uci.edu/dataset/267/banknote+authentication
1372 instances, 4 features, binary classification

## Dependencies
numpy, pandas, matplotlib, seaborn, scikit-learn

## How to run
Open the .ipynb in Google Colab, place the dataset .txt in the working directory, run cells sequentially.

## Contents
- Notebook: EDA, preprocessing, from-scratch perceptron, training, evaluation
- Report: LaTeX-generated PDF with full analysis
